# 桌面暖喵 · nikki-desktop-pet

暖暖和大喵陪你敲键盘、使用鼠标的 Windows 桌宠。

## 下载与安装

👉 [下载最新安装包和安装指南](https://github.com/shousiyouyu/nikki-desktop-pet/releases/latest)

解压安装包，运行 `桌面暖喵安装程序.exe`。可通过“浏览…”选择安装位置，升级时保留本机个人数据。详细步骤见安装包中的 `安装指南.txt`。

## 功能

- 暖暖和大喵、暖暖、大喵三种角色，手部和眼神跟随
- 每日按键与鼠标点击统计、键位热力图、小时曲线
- 键盘和鼠标可独立切换莓粉、桃红两种款式
- 便利贴记事自动保存，待办支持设定时间和到时提醒
- 自行配置模型接口、API 密钥、独立角色卡与限定资料库，聊天历史保存在本机

## 使用说明

适用系统：Windows 10、Windows 11。

聊天需要自行配置可用的模型服务和 API 密钥，安装包不提供共享密钥或模型额度。

程序运行时才会即时提醒待办；退出或关机期间错过的待办，会在下次启动时补提醒。

个人数据保存在 `%LOCALAPPDATA%\KeycatDesktop`。发布文件不包含作者的密钥、聊天历史、记事或统计数据。

当前仓库用于发布 Windows 安装包与指南。
